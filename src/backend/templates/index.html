Agrupamento Facial com Deep Learning em fotos do Google Drive

Faça login com sua conta do Google para conectar suas pastas de fotos. O sistema utiliza RetinaFace e ArcFace para agrupar pessoas automaticamente em centróides vetoriais de 512 dimensões com PostgreSQL pgvector.

Cadastro instantâneo via API oficial do Google. Não armazenamos senhas.
Desenvolvendo localmente sem credenciais Google?

Modelos de Visão de Ponta

RetinaFace com SCRFD para detecção anatômica precisa de 5 pontos faciais e ArcFace para embeddings normalizados L2 de 512 dimensões.

PostgreSQL 16 + pgvector

Busca vetorial por similaridade de cosseno direto no banco de dados com índices HNSW. Performance de milissegundos sem bancos separados.

Streaming Volátil em RAM

As fotos são lidas em buffer de memória (io.BytesIO) diretamente da Google Drive API v3 e nunca salvas em disco físico, garantindo privacidade máxima.

Como registrar a aplicação no Google Cloud Console:

Para ativar a integração real com o Google Drive e o login automático, você deve registrar o projeto no Google Cloud e adicionar 3 chaves ao seu arquivo .env:

GOOGLE_CLIENT_ID=seu_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=seu_client_secret
GOOGLE_REDIRECT_URI=http://localhost:8000/api/v1/google/oauth/callback/
